# Security Policy

## Reporting Security Vulnerabilities

We take the security of Mercato seriously. If you discover a vulnerability, please report it responsibly.

### How to Report

Please **do not** report security vulnerabilities through public GitHub issues or public channels.

Instead, please report security issues through **GitHub Private Vulnerability Reporting**:
1. Navigate to the **Security** tab of the repository on GitHub.
2. Under "Reporting", click **Report a vulnerability**.
3. Provide detailed steps to reproduce the issue, including request payloads, expected versus actual behavior, and potential impact.

Maintainers will review the submission promptly and coordinate a fix and disclosure.
